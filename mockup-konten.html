Reading this mockup: amber = expenses, green = income, blue = computed totals, red = alert only (§2.8a). Tag pills carry their own color layer (§2.5): purple = allocation tag, teal = grouping/project, indigo = grouping/claim, slate = grouping/statement, rose = grouping/claim-category. Yellow now marks only the specific missing field — e.g. the "AMAZON PAYMENTS" row's Kategorie cell — never a full-row wash; the dependent Unterkategorie cell shows a plain "blocked/disabled" look until Kategorie is chosen, distinct from an actual missing-data flag. The Kategorie/Unterkategorie pair on the "Market Magasin" row is a live demo — change Kategorie and watch Unterkategorie clear, flag yellow, and refilter. The arrow column between Konto 1/2 is now a plain bold unicode arrow in the interface font, no tint or background — populated only for real transfers (Consors row). Two open-item examples, both now closed the same way: Pharmacie is part of a tagged CPAM claim (indigo "GW1298747" pill), and "Thomas (Geldbeutel vergessen)" is a standalone loan (Außenstände, §3g) — neither needs any manual action anymore; both dots clear themselves automatically the instant their tag's signed total nets to zero. The old manual 🔗 link-picker is retired entirely. The split transaction ("Airbus Gehalt") uses an expand chevron + "N Positionen" hint instead of a dedicated Aggregat column. The focused cell outline (bottom row, "31.07.") illustrates the keyboard-navigable grid state. Figures are set in a monospace/tabular numeral font throughout so columns of amounts always align. New: the filter/search bar above the grid — a live quick-filter search box (matches name, comments, and amount at once), date-range presets (Jahr/Monat/Tag/Benutzerdefiniert — Jahr just reflects the global year selector), and a saved-filters menu (⭐, top right) for recalling or creating named filter combinations. Active filters render as removable chips underneath, with a running "N von M Buchungen" count and a one-tap "Alle zurücksetzen." Every filter shown is single-value-per-field, by design — Konten stays on AG Grid's free Community tier rather than needing Enterprise's multi-select column filters. On phone, the same idea condenses to a search field plus horizontally-scrolling filter chips. New: "Kürzlich gelöscht" toggle (§2.9a) next to the saved-filters button — off by default; switched on, deleted-but-not-yet-purged transactions from roughly the last week reappear, struck through and dimmed, each with its own "Wiederherstellen" button (the Gartenschlauch row is a live demo — toggle it to see the row appear, click restore to remove it again). Not a keyboard shortcut on purpose — deleting a row clears AG Grid's own cell-edit Undo/Redo stack by design, so this toggle is the actual recovery path for a deleted transaction, not `Ctrl+Z`.
