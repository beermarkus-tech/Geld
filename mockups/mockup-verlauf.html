Reading this mockup: three real sticky columns now, matching the actual Gsheet structure — Kategorie (rotated, spans the whole group, e.g. "Sonstiges"), Unterkategorie (spans only that subcategory's own rows, e.g. "Urlaube"), and a third column combining each row's label + yearly total (Prog/Plan 1/Plan 0, or a breakdown item's name when applicable) — breakdown names never touch the Unterkategorie column, exactly as in the sheet. Both label columns use dynamically recomputed rowspan (not a static HTML rowspan): every time a row is hidden or shown, a small script recounts how many visible rows belong to that category/subcategory and resizes the spanning cell accordingly — this is what makes "Urlaube" correctly shrink when its breakdown rows collapse, the same way Google Sheets' merge behaves. Try the Plan 0 toggle, the global breakdown toggle, and the individual ▾ arrows on Plan 1/Plan 0 to see the spans resize live. Breakdown rows keep their distinct lavender tint, covering the full row including the Unterkategorie cell's edge. New: Plan 1's Urlaube breakdown now shows a blue-tinted "Schottland (automatisch)" header row above its own children (Unterkünfte, Flug & Auto) — this one row is computed, not typed: it mirrors the children's Plan 1 sum for any month not yet closed (Aug–Dez here), and becomes the real tagged total from Konten for any month that is closed (Jan–Jul) — July shows −2.705 €, a deliberately small gap under the children's planned −2.754 €, to illustrate that this is a live comparison sitting *next to* the manual plan, never overwriting it. This automated row only ever appears inside Plan 1's block, never Plan 0's, and only where breakdown lines actually share a common parent tag — a flat, unnested breakdown line gets no such row. Also new: any cell that's genuinely zero now renders **empty** rather than showing "0", across every row type — quieter grid, easier to spot where something real is happening. On phone, navigation is one month at a time.
